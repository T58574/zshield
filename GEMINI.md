# ZShield (V-Shield) 🛡️ — Краткий обзор проекта

## 🌟 Что это такое?
**ZShield** — это современный VPN-клиент с акцентом на приватность и премиальный дизайн. Проект нацелен на создание удобного инструмента для обхода блокировок с использованием передовых протоколов.

### Основные особенности:
*   **Мощное ядро:** Использует **Xray-core** (VLESS, V2Ray) для стабильного и быстрого соединения.
*   **Премиальный UI:** Дизайн в стиле **Glassmorphism** (эффект матового стекла), вдохновленный современными концептами интерфейсов.
*   **Кроссплатформенность:** Разрабатывается на **Flutter** для работы на Windows, Android, iOS и других ОС.

---

## 🛠️ Технический стек (простыми словами)
1.  **Flutter (Dart):** Отвечает за внешний вид и взаимодействие с пользователем.
2.  **Riverpod:** "Мозг" приложения, который управляет состоянием (подключен/отключен, выбор сервера).
3.  **Xray-core:** "Мотор" под капотом, который занимается шифрованием и передачей данных.
4.  **GoRouter:** Система навигации между экранами.

---

## 📂 Структура проекта (где что искать)
*   `lib/screens/` — Основные страницы: Dashboard (главная), Settings (настройки), Routing.
*   `lib/providers/` — Логика работы приложения: состояние VPN, сохранение настроек.
*   `lib/widgets/` — Дизайнерские компоненты: стеклянные панели (`GlassPanel`), кнопки и индикаторы.
*   `lib/core/` — Конфигурация приложения, темы и роутинг.

---

## 🤖 Заметки для разработчика (Context for AI)
*   **State Management:** Используем Riverpod 2.x (Notifier). Избегать устаревшего StateNotifier.
*   **Стиль кода:** Весь UI должен придерживаться темы Glassmorphism. Используй `GlassPanel` и `AppTheme`.
*   **Навигация:** Только через `GoRouter`.
*   **VPN Логика:** Работает через плагин `flutter_v2ray_plus`.

## 🚀 Как запустить
1.  `flutter pub get` — загрузить зависимости.
2.  `flutter run` — запустить проект.
