# 🚀 Инструкция по запуску ZShield

Этот документ поможет вам настроить окружение и запустить проект ZShield (V-Shield) на вашем локальном компьютере.

## 📋 Предварительные требования

Перед началом убедитесь, что у вас установлены:
1.  **Flutter SDK** (версия ^3.11.5). [Инструкция по установке](https://docs.flutter.dev/get-started/install).
2.  **Dart SDK** (устанавливается вместе с Flutter).
3.  **Git** для клонирования репозитория.
4.  **C++ Build Tools** (для Windows): Установите "Desktop development with C++" через Visual Studio Installer.

---

## 🛠️ Первичная настройка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/zshield.git
    cd zshield
    ```

2.  **Загрузите зависимости:**
    ```bash
    flutter pub get
    ```

3.  **Проверьте состояние системы:**
    ```bash
    flutter doctor
    ```
    Убедитесь, что нет критических ошибок для целевой платформы (Windows/Android).

---

## 🏃 Запуск проекта

### Режим разработки (Debug)
Для запуска приложения используйте команду:
```bash
flutter run
```
Если у вас подключено несколько устройств, выберите нужное (например, `-d windows`).

---

## 📦 Компиляция (Сборка Release)

Чтобы собрать готовый файл для распространения:

### 1. Windows (.exe)
```bash
flutter build windows
```
Результат будет находиться в: `build/windows/runner/Release/zshield.exe`.
*Примечание: Для работы также потребуются .dll файлы из той же папки.*

### 2. Android (.apk)
```bash
flutter build apk --release
```
Результат: `build/app/outputs/flutter-apk/app-release.apk`.

## 🤖 Автоматизация (CI/CD)

Для автоматической сборки при каждом пуше в GitHub, мы используем **GitHub Actions**.

### Настройка GitHub Actions:
1. Создайте файл `.github/workflows/build.yml` в корне проекта.
2. Вставьте туда конфигурацию для сборки (см. ниже).
3. При каждом `git push` GitHub будет автоматически собирать `.exe` и `.apk`.

### Пример конфигурации CI/CD (GitHub Actions):
```yaml
name: Build ZShield

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build_android:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: subosito/flutter-action@v2
        with:
          channel: 'stable'
      - run: flutter pub get
      - run: flutter build apk --release
      - uses: actions/upload-artifact@v3
        with:
          name: android-apk
          path: build/app/outputs/flutter-apk/app-release.apk

  build_windows:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v3
      - uses: subosito/flutter-action@v2
        with:
          channel: 'stable'
      - run: flutter pub get
      - run: flutter build windows
      - name: Archive Release
        uses: thedoctor0/zip-release@master
        with:
          type: 'zip'
          filename: 'zshield-windows.zip'
          directory: 'build/windows/runner/Release'
      - uses: actions/upload-artifact@v3
        with:
          name: windows-binary
          path: build/windows/runner/Release/zshield-windows.zip
```

## ⚠️ Важные замечания
*   **Core-бинарники:** Убедитесь, что в папке `assets/core/` лежат актуальные файлы `xray.exe` (для Windows) и соответствующие версии для других ОС. Они прописываются в `pubspec.yaml`.
*   **Подписи (Signatures):** Для Android-релиза рекомендуется настроить `key.properties` для подписи APK, иначе Google Play его не примет.
